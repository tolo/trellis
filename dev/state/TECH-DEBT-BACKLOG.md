| TD-011 | trellis_site | Theme SASS param values are not validated for structural CSS characters (`;`, `{`, `}`). `theme_sass_generator.dart` `_toSassValue` neutralizes SASS *interpolation* (`#{...}`, so it can't be evaluated — remediated in the 0.10.0 follow-up review), but a value carrying `;{}` still reaches the generated SCSS: a **string** value silently corrupts the output CSS (e.g. `content: a; } html { background: red;` closes the rule early and injects another), and a raw **color** value aborts the compile. **Scope — two sinks, values *and* names:** the same values also flow into the second emit sink `css/theme-props.css` (`_generateCssCustomProperties` / `_toCssValue`) — plain CSS copied verbatim to output with **no** compile gate, so corruption there is always silent (it never aborts).
