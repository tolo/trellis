## Content

Markdown files under `content/` become pages. `_index.md` defines the home page
or a section listing; each other file becomes a single page.

## Configuration

`trellis_site.yaml` selects the Arbor theme from this checkout and enables the
search index. No site-local layouts or styles are needed.
