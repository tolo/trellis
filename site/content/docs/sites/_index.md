Trellis turns Markdown content and HTML layouts into a complete static site with
one Dart-native toolchain.

- [**Getting Started**](/docs/sites/getting-started/) – create, build, preview,
  and deploy your first site.
- [**Content**](/docs/sites/content/) – organize Markdown, front matter, page
  bundles, drafts, and shortcodes.
- [**Layouts**](/docs/sites/layouts/) – render pages with the template context,
  navigation, taxonomies, and pagination.
- [**Themes**](/docs/sites/themes/) – install and customize a reusable design.
- [**Search and feeds**](/docs/sites/search-and-feeds/) – publish discovery
  artifacts for readers and clients.
- [**Deploy**](/docs/sites/deploy/) – serve from a domain root or sub-path and
  validate every built link.
