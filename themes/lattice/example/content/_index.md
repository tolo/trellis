Everything below the hero is ordinary page content. Lattice renders a landing page and a full documentation
surface from the same theme, so the marketing page and the reference material share one visual language
instead of drifting apart.

Sections, the in-page index, and previous/next travel all come from the content tree — add a folder and the
navigation follows.
