## About This Blog

This is a sample blog built with [Trellis](https://pub.dev/packages/trellis) and the Verdant theme.

Trellis is a Thymeleaf-inspired HTML template engine for Dart. The Verdant theme provides a clean,
accessible, responsive design for blogs built with the Trellis SSG (`trellis_site`).
