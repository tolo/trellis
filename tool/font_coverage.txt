# Expected character coverage of every vendored WOFF2, one entry per face.
#
# This is the other side of the subsetting contract. `tool/subset_fonts.py --verify` rebuilds
# each face from pinned upstream and compares SHA-256, which proves only that the bytes match
# the recipe that produced them: narrow LATIN/ARROWS/MARKS in that script, run --write, and
# the comparison happily agrees with the smaller font. So the coverage a face must carry is
# pinned here instead, and --verify asserts the built cmap against it.
#
# Nothing generates this file. It was frozen from the shipped faces once they were verified
# byte-identical to a fresh build, and a deliberate coverage change is a hand edit reviewed in
# the diff - `--write` prints the replacement block for each face whose coverage moved.
#
# Format: `<theme>/<stem>:` then indented `U+XXXX` / `U+XXXX-YYYY` tokens, `#` comments.
# These are the codepoints the face *draws*, not the ones the recipe asks for: a family that
# does not draw a requested codepoint simply does not emit it (see subset_fonts.py).
